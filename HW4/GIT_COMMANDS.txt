WEEK 4 — COPY/PASTE COMMANDS

A. FIRST UPLOAD
git init -b main
git add .
git commit -m "Initial commit - NQU Smart Campus System"
git remote add origin YOUR_MAIN_REPOSITORY_URL
git push -u origin main

B. BRANCH
git checkout -b developGitBranch
# Make one small edit and save it.
git add .
git commit -m "Update NQU Smart Campus System in development branch"
git push -u origin developGitBranch

C. MERGE
git checkout main
git pull origin main
git merge developGitBranch
git push origin main

D. FORK
Use GitHub > Fork, then:
git clone YOUR_FORK_REPOSITORY_URL
# Make one small edit in the cloned fork.
git add .
git commit -m "Update project from fork"
git push

E. PULL REQUEST
GitHub fork page > Contribute / Compare & pull request > Create pull request.

F. README
Replace the PASTE_... placeholders with the actual GitHub evidence URLs.
